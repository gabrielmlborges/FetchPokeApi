# Fetch PokeApi #
Projeto pessoal de aprendizado focado em aprender os fundamentos de desenvolvimento web (Vanilla JS) e consumo de APIs REST.

## Tecnologias e Ferramentas
- **Linguagem:** JavaScript (ES6+)
- **Estilização:** CSS3
- **Estrutura:** HTML5
- **Bundler:** Parcel (Gerenciamento de dependências e build)
- **Arquitetura:** MVC (Model-View-Controller)

## Funcionalidades ##
- Listar Pokemons por regiao
- Procurar Pokemons pelo nome
- Visualizar informacoes detalhadas de Pokemons
- Favoritar Pokemons (salvos em local Storage)
- Responsivo em celulares e desktops

## Como executar o projeto ##
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.

1. Clone o repositório:
```
bash
git clone [https://github.com/gabrielmlborges/FetchPokeApi](https://github.com/gabrielmlborges/FetchPokeApi)

```
2. Instale as dependências (necessário para o Parcel):
```
bash
npm install

```
3. Inicie o servidor de desenvolvimento:
```
bash
npm start

```
4. Acesse em seu navegador: http://localhost:1234
